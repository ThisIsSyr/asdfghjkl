# 光伏电站设计规范与设计缺陷排查

## 电站设计关键参数
### 组串设计
- 组串串联数：由逆变器 MPPT 电压范围和组件 Voc 决定
- 组串最大开路电压：Voc × N × 温度修正系数（-0.3%/°C）≤ 逆变器最大输入电压
- 组串最小工作电压：Vmp × N × 温度修正 ≥ 逆变器 MPPT 最小电压
- 设计裕度：冬季最低温取 -20°C~-40°C（地域差异），留 10% 电压裕量

### 支架与倾角
- 最佳倾角 = 纬度 × 0.76 + 3.1°（经验公式）
- 前后排间距 = 组件高度 / tan(太阳高度角)，冬至日 9:00~15:00 无遮挡
- 支架材料：热浸镀锌钢（镀锌层 ≥ 65μm）或铝合金
- 地基类型：混凝土灌注桩、螺旋桩、预制桩（按地质条件选择）

### 电缆与电气
- 直流电缆压降 ≤ 1%（组串至汇流箱）和 ≤ 2%（汇流箱至逆变器）
- 交流电缆压降 ≤ 3%（逆变器至并网点）
- 防雷设计：组件边框接地电阻 ≤ 4Ω，逆变器处 ≤ 1Ω
- 直流侧需配置直流隔离开关和熔断器

## 常见设计缺陷
### 阴影遮挡
- 设计问题：前后排间距不足，冬季遮挡严重
- EL 表现：被遮挡组件的遮挡区域呈暗区（旁路二极管激活）
- 危害：长期遮挡导致旁路二极管频繁工作、局部热斑
- 改进：重新核算间距，优化倾角，采用跟踪支架

### 通风散热不足
- 设计问题：组件背面距屋面 < 10cm，通风不良
- EL 表现：组件温度高，间接加速 PID 和 EVA 老化
- 危害：温度每升高 1°C，功率下降 0.35%~0.45%
- 改进：增加安装高度 ≥ 15cm，屋顶加装通风通道

### 结构荷载不足
- 设计问题：未考虑极端雪荷载或风荷载
- EL 表现：隐裂增多，组件边框变形
- 改进：按 50 年一遇极端天气设计，增加结构安全系数

### 电气失配
- 设计问题：同一 MPPT 接入不同朝向/倾角的组串
- EL 表现：无直接 EL 特征，但 I-V 出现台阶
- 危害：MPPT 无法同时追踪多个最大功率点，效率损失 3%~10%
- 改进：不同朝向组串用不同 MPPT 或独立逆变器
