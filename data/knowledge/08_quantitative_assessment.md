# 光伏组件定量评估与评级算法

## 缺陷面积量化
### 像素面积计算
- 缺陷面积(px) = Σ(缺陷类别像素数)，通过语义分割模型直接统计
- 缺陷面积占比 = 缺陷面积(px) / 组件总面积(px)
- 组件总面积：电池区域有效像素总数，排除边框和汇流条

### 物理面积换算
- 单像素物理面积 = (组件实际尺寸 / 图像分辨率)²
- 缺陷物理面积(cm²) = 缺陷像素面积 × 单像素物理面积
- 对于 300W 组件（约 1650×992mm），有效电池面积约 1.6m²

## 置信度加权评估
- 高置信度区域（> 0.95）：直接计入严重缺陷
- 中置信度区域（0.85~0.95）：标记为"需人工复核"
- 低置信度区域（< 0.85）：建议重拍确认

### 加权缺陷面积
- WDA = Σ(类别面积占比 × 类别权重 × 置信度)
- 裂纹权重：1.0；断栅权重：0.8；接触不良权重：0.7；腐蚀权重：0.9

## 严重度分级算法
| 等级   | 缺陷面积占比 | 动作                              |
|--------|-------------|----------------------------------|
| 正常   | < 1%        | 常规巡检                          |
| 轻微   | 1%~3%       | 3个月后复检                       |
| 中等   | 3%~8%       | 标记组件，1个月内复检或修复       |
| 严重   | ≥ 8%        | 立即停用，评估更换                |

### 附加升级条件
- 裂纹穿越 ≥ 3 条主栅 → 升一级
- 单个连通域面积 > 5000px → 升一级
- 腐蚀区域靠近组件边缘 > 5cm → 升一级
- 置信度 < 0.7 的整体预测 → 降一级（需人工确认）

## 组件健康评分 (PV Health Index)
- PHI = 100 × (1 - 加权缺陷面积占比) × 置信度修正因子
- PHI ≥ 95：优秀，正常服役
- 85 ≤ PHI < 95：良好，加强巡检
- 70 ≤ PHI < 85：一般，建议修复
- PHI < 70：差，建议更换

## 检测置信度综合分析
- 模型置信度均值 (MCS)：所有非背景像素的平均 softmax 概率
- MCS > 0.95：检测结果高度可信
- 0.85 < MCS < 0.95：检测结果可信，但建议抽查
- MCS < 0.85：检测结果仅供参考，应安排人工复检
