# 光伏系统级故障诊断（逆变器与电气系统）

## 逆变器故障与 EL 关联
### 组串电流低
- 逆变器告警：组串电流 < 额定值 50%
- EL 排查：组串中可能存在断栅、腐蚀严重的组件
- 定位方法：逐块检测或通过组串 I-V 曲线判断

### MPPT 效率低
- 逆变器告警：MPPT 跟踪效率 < 95%
- EL 排查：组串 I-V 曲线出现台阶，说明存在严重失配
- 常见原因：组串中某块组件严重衰减或旁路二极管激活

### 绝缘阻抗低
- 逆变器告警：绝缘阻抗 < 500kΩ（预警值）或 < 100kΩ（跳闸值）
- EL 排查：检查组件边框腐蚀、接线盒进水、电缆破损
- 典型表现：PID 腐蚀组件绝缘阻抗大幅下降

### 直流电弧
- 逆变器告警：AFCI（电弧故障断路器）触发
- EL 排查：接线盒接触不良、连接器虚接、电缆破损
- 风险：直流电弧温度 > 3000°C，可能引发火灾

## 常见系统故障诊断流程
### 故障一：发电量低于预期
1. 查看逆变器发电量曲线，确认是整体偏低还是个别时段偏低
2. 检查是否阴影遮挡（对比实际阴影与设计假设）
3. EL 抽检，排查大面积隐裂或 PID
4. I-V 测试，评估功率衰减程度
5. 清洁组件后对比发电量（排除积灰因素）

### 故障二：逆变器频繁启停
1. 检查电网电压是否波动过大（> ±10%）
2. 检查直流侧绝缘阻抗是否过低
3. 检查交流侧滤波电容是否老化
4. EL 检查是否存在导致漏电流的组件缺陷
5. 检查逆变器散热风扇是否正常

### 故障三：组串电流异常偏低
1. 测量组串开路电压 Voc（正常为 N × 组件 Voc）
2. 测量组串短路电流 Isc
3. 对比同类型组串参数
4. 对偏差 > 5% 的组串进行逐块 I-V 测试
5. EL 扫描异常组件

## 监控告警与响应
| 告警类型       | 阈值                | 响应时间 | 动作                   |
|---------------|---------------------|---------|-----------------------|
| 组串电流偏差   | > 15%               | 1 天    | 排查 + EL 抽检         |
| 绝缘阻抗低     | < 500kΩ             | 立即    | 停运排查               |
| 直流电弧       | 检测到              | 立即    | 自动断开 + 人工排查     |
| 逆变器停机     | -                   | 2 小时  | 远程诊断 + 现场恢复     |
| 功率低于预期   | > 10%               | 3 天    | 对比分析 + 现场检测     |
